# Reports (LaTeX)

- One shared preamble at `reports/_template/preamble.tex`. Each phase has `reports/phaseN/main.tex`
  that inputs it via a relative path.
- **Never edit the preamble without asking.** Colours only through the named palette; no inline hex.
- Build: `latexmk -pdf -outdir=build main.tex` from the phase folder. Build output is gitignored.
- Figures are generated by `src/smart_meter_analytics/viz` into `reports/figures/`, never hand-made.
- Do not write body text unless asked. Review for clarity, rubric coverage, and page limits.
- Phase 1: 2-3 pages excluding references. Label sources as confirmed vs planned.
- Overleaf: upload the whole `reports/` folder so relative paths keep working.
